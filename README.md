# Luz Tech TI

Site institucional compacto da Luz Tech TI, desenvolvido em HTML, CSS e JavaScript puro para hospedagem estática.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos e responsividade
- `js/script.js` — menu mobile, animações e ano automático
- `assets/favicon.svg` — favicon

## Antes de publicar

No `index.html`, substitua todas as ocorrências de:

`5500000000000`

pelo número real do WhatsApp da Luz Tech TI, usando o formato internacional sem `+`, espaços ou símbolos.

Exemplo:

`5511999999999`

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta mantendo a estrutura de diretórios.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Não é necessário Node.js, npm, build ou backend.
